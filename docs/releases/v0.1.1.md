# Component Vault v0.1.1

Component Vault v0.1.1 focuses on responsive UI reuse across different Studio viewport sizes and adds built-in update notifications.

## Highlights

- Preserve the root component's relative screen position when inserting into a different viewport or parent size.
- Scale offset-based UI throughout the saved hierarchy so nested controls, padding, layout spacing, text sizes, and common pixel thickness values adapt with the destination viewport.
- Preserve existing Scale values and AnchorPoint behavior.
- Keep AutomaticSize components automatic while scaling their pixel-based content and padding.
- Respect layout-controlled placement for UIListLayout/UIGridLayout parents.
- Add an in-plugin update checker for official GitHub releases.
- Cache update checks to avoid unnecessary requests.
- Show the current plugin version and update status in the Component Vault window.
- Provide the official GitHub release link when a newer release is available.
- Keep update checks non-blocking when HTTP access or network connectivity is unavailable.

## Compatibility

- Existing v0.1.0 saved libraries remain compatible.
- Components saved before v0.1.1 do not contain the new responsive viewport metadata. Re-save or Update those components to enable responsive insertion behavior.
- Updating the plugin does not delete or replace the user's saved Component Vault library.
- v0.1.0 itself cannot receive update notifications retroactively because the updater did not exist in that release.

## Manual validation completed

The responsive insertion changes were manually checked in Roblox Studio using 1366×768 and 780×360 device presets, including:

- non-zero AnchorPoint
- AutomaticSize
- nested UI
- UIListLayout-controlled content

## Installation

Download `ComponentVault.rbxm` from the v0.1.1 GitHub release, replace the older local plugin file, and restart Roblox Studio.
