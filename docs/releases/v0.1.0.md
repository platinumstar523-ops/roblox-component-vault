# Component Vault v0.1.0 — draft release notes

> **Draft only.** v0.1.0 has not been tagged or published yet.

Component Vault v0.1.0 is planned as the first public preview of a reusable Roblox Studio UI-component library.

## Highlights

- Save supported Roblox UI hierarchies as reusable named components.
- Keep a local component library available across Studio places.
- Insert saved components back into Studio as normal Roblox Instances.
- Preview components directly in the library.
- Update, rename, tag, search, sort, filter, and delete saved components.
- Use Studio Undo after insertion.
- Export and import the full library as portable text.
- Avoid destructive imports by regenerating IDs and suffixing duplicate names.

## Supported data

The first release focuses on common Roblox UI classes and properties, including frames, text/image controls, scrolling/canvas UI, decorators, constraints, gradients, layouts, and several modern font/layout settings.

Roblox datatypes used by supported properties are encoded into a versioned plain-data format and reconstructed when a component is inserted.

## Safety and compatibility behavior

- Unsupported descendants/properties produce warnings rather than being silently guessed.
- Unsupported future component/export schema versions are rejected.
- Imported data cannot request arbitrary Roblox Instance classes through the rebuilder.
- Local-library saves are verified by reading plugin storage back before success is reported.

## Known limitations

- The main library is local to the current Studio installation; there is no cloud/team sync.
- Not every Roblox UI class or property is supported yet.
- Thumbnail previews are best-effort and may differ from the final inserted component.
- Transfer currently uses copied JSON text rather than files or hosted sharing.
- There is no component version history, design-token/theme system, or shared team library yet.

## Installation

The final GitHub release should include a tested `ComponentVault.rbxm` artifact. Until that release exists, build from source using the instructions in the repository README.
