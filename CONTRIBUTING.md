# Contributing to Component Vault

Thanks for your interest in contributing. Component Vault is in early development, so the project structure and APIs may change quickly.

## Ways to Contribute

- Report bugs with clear reproduction steps.
- Suggest focused features or workflow improvements.
- Improve documentation or examples.
- Submit fixes or features through pull requests.

## Development Workflow

1. Fork or clone the repository.
2. Create a branch for one focused change.
3. Keep commits small and descriptive.
4. Test the change in Roblox Studio when applicable.
5. Open a pull request that explains what changed and why.

Suggested branch names include `feature/component-library`, `fix/selection-handling`, and `docs/getting-started`.

## Code Guidelines

- Prefer readable Luau over clever abstractions.
- Keep modules focused on one responsibility.
- Avoid introducing dependencies unless they clearly improve the project.
- Preserve normal Roblox Instance behavior wherever possible.
- Document non-obvious behavior and architectural decisions.

## Pull Requests

A useful pull request should include:

- A concise summary of the change.
- The problem it solves.
- How it was tested.
- Screenshots or recordings for visible UI changes when useful.

## Conduct

Be respectful and constructive. Critique code and ideas rather than people.
